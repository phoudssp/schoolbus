SafeRide School Bus Platform

A complete operating system for a bus company serving multiple schools. Live tracking, doorstep pickup, NFC + QR scanning, score management, parent absence requests — all in one place.

Operator (Super Admin)

The bus company's full admin panel. Live monitoring with moving buses, route planning with doorstep pickup, schools, students, parents, drivers, fleet, plans, billing, reports, and admin user management.

12 modules Live monitor

School Admin

Per-school dashboard. See live bus arrivals and check-ins, manage attendance, approve parent absence requests, and enter scores per student × subject — instantly visible in the parent app.

Score management Absence approvals

Parent App (Phone)

Phone-shaped mobile app. See where each child's bus is in real time, get push notifications on the 4 daily events, view scores from school, and request absences with one tap.

Multi-child EN + Lao

Driver Tablet

Tablet mounted in the bus. Today's stops in order, expected manifest at each stop, big QR scan + NFC tap buttons, manual override for forgotten cards, and the mandatory walk-the-bus check at end of route.

QR + NFC Walk-bus check

How everything connects

Operator manages buses + drivers + routes → Driver scans student card on the bus → Live event flows to parent app and school admin → School records attendance and scores → Parent sees scores and can request absence → School approves absence → Operator sees the entire fleet across every school they serve, in real time.
